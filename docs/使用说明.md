# abqhpc 使用说明

## 环境要求

| 侧 | 要求 |
|----|------|
| Windows | PowerShell 5.1+；`client\lib\Renci.SshNet.dll`；下载文件夹需本机 `tar.exe` |
| 超算 | `python3`（标准库 `sqlite3` 即可）；登录节点可互 `ssh`（BatchMode） |

## 登录

- 地址与端口由 `abqctl.ps1` 内置（`60.245.128.10:65010`，用户 `tsyg`）。
- 密码 = 静态前缀 `tsyg6100` + **6 位动态码**。面板只填动态码。
- `connect` 起一个本机宿主进程保持 SSH/SFTP；后续命令走本机 TCP，**OTP 不写磁盘**。
- 会话断了需换新动态码重新 `connect`。

## 单作业客户端（`client/abqctl.ps1`）

| 命令 | 说明 |
|------|------|
| `connect <OTP>` | 登录并保持会话 |
| `disconnect` | 断开 |
| `upload <本地文件> [远端目录]` | 默认远端 `/public/home/tsyg/wh-data` |
| `browse [路径]` | 预览目录或文件头 |
| `download` / `download-dir` | 下载文件/目录 |
| `run <远程.inp> [-Cpus N] [-Double both\|explicit\|off]` | 直接提交 |
| `status` / `sta` / `log` / `cancel` | 状态与取消 |
| `gui` | 打开统一面板 `AbqCtlGui.ps1` |
| `queue-gui` | 同上，默认切到「批量队列」Tab |

也可双击 `打开任务面板.bat` / `打开队列面板.bat`。

**统一 GUI**：顶部连接；两个 Tab——「单作业 / 传输」与「批量队列」（调度器、入队、队列表）。单作业页可将当前 inp「加入批量队列」。

## 批量队列（`client/AbqQueue.ps1` + GUI Tab）

依赖：**同一条已连接的 abqctl 会话**（共用 `%TEMP%\abqctl_ssh\session.json`）。

### 超算侧组件

同步目标：`/public/home/tsyg/tsyg/abqctl_queue/`

| 文件 | 作用 |
|------|------|
| `schema.sql` / `abqctl_db.py` | SQLite：`jobs`、`scheduler_lease`、`node_snapshots` |
| `abqctl_node_scan.py` | 扫 Abaqus 进程与负载 |
| `abqctl_scheduler.py` + `.sh` | nohup 调度主循环 |

### 命令

```text
.\AbqQueue.ps1 sync
.\AbqQueue.ps1 scheduler-status | scheduler-start | scheduler-stop
.\AbqQueue.ps1 enqueue <远程.inp> [-Cpus 8] [-Double both] [-Priority 0] [-Node login08]
.\AbqQueue.ps1 list [status]
.\AbqQueue.ps1 cancel <id>
.\AbqQueue.ps1 nodes
.\AbqQueue.ps1 jobs-running
.\AbqQueue.ps1 gui
```

### 作业状态

`waiting` → `starting` → `running` → `done` | `failed`  
仅 `waiting` 可 `cancel` → `cancelled`。`starting` 超时会回 `waiting`。

### 调度策略（默认）

| 变量 | 默认 | 含义 |
|------|------|------|
| `ABQCTL_NODES` | `login05 login08 login10` | 候选登录节点 |
| `ABQCTL_CPU_FACTOR` | `0.8` | 可用核 = nproc×因子 − 已用估算 |
| `ABQCTL_MAX_JOBS_PER_NODE` | `2` | 每节点最大并行 |
| `ABQCTL_SCHED_INTERVAL` | `15` | 调度周期（秒） |
| `ABQCTL_LEASE_SEC` | `45` | 租约时长 |

按 `priority DESC, id ASC` 取队头；资源不够则本轮不放行。

### 多客户端

- 均可入队、列表、取消 waiting、看节点。
- 同时仅一个调度器持有 `scheduler_lease`；重复 `scheduler-start` 会提示已在跑。
- 全部客户端退出后，超算 nohup 进程仍继续消化队列。

## 推荐联调步骤

1. `connect` → `AbqQueue.ps1 sync` → `scheduler-start`
2. `enqueue` 两个 inp → `list` 观察 `waiting`→`running`→`done`
3. 第二台机器 `list` 应看到同一队列；lease owner 唯一
4. `scheduler-stop` 后再 `start`，应能继续
5. `jobs-running` 能列出节点上已有 `explicit_dp`（只读）

## 源码与部署关系

- **本仓库**是唯一本地源码树：`client/` + `remote/`。
- Windows 不跑调度循环；调度只在超算 `nohup`。
- 改 `remote/` 后务必再执行 `sync`（或 GUI「同步脚本」）。
